# 🚀 YouTube Growth & SEO Studio (vidIQ Web Suite)

Полноценная веб-платформа для YouTube-авторов, маркетологов и аналитиков. Прямой аналог **vidIQ** и **TubeBuddy** с глубоким SEO-аудитом, детекцией вирусных аномалий (Outliers), оценкой вовлеченности (VPH/ER), исследованием ключевых слов и AI Growth Studio.

---

## 🌟 Ключевые возможности

### 1. 🔍 SEO-Инспектор видео (SEO Score 0–100)
- **Комплексная оценка SEO (0–100)**: оценка по 20+ факторам ранжирования YouTube.
- **Инспектор скрытых тегов**: просмотр всех тегов любого видео конкурентов с возможностью копирования в 1 клик.
- **Интерактивный чек-лист**: точечные подсказки по оптимизации заголовка, описания, тегов и превью.
- **Метрики скорости и вовлеченности**: расчет **VPH** (просмотры в час) и **ER%** (вовлеченность аудитории).

### 2. 📊 Аудит канала & Динамика роста
- Анализ последних 30 видео канала с графиками динамики просмотров (ApexCharts).
- Расчет **медианы канала** (базового уровня просмотров).
- Анализ регулярности и расписания: лучший день недели для публикации и интервал между видео.
- Прогноз просмотров на 30 дней вперед.

### 3. ⚡ Детектор виральности и выбросов (Outliers Hunter)
- Автоматический расчет **Outlier Multiplier** (во сколько раз ролик превзошел средний уровень канала: например, *3.8x Viral Outlier*).
- Быстрый поиск тем с вирусным потенциалом.

### 4. 🔑 Keyword Research Lab
- **Реальные автокомплиты YouTube**: сбор подсказок из поисковой строки.
- Расчет **Search Volume** (объем поиска) и **Competition Difficulty** (сложность конкуренции).
- **Opportunity Score**: поиск тем с высоким спросом и низкой конкуренцией.
- Топ-10 видео конкурентов по запросу с их VPH.

### 5. ⚔️ Битва конкурентов (Head-to-Head Battle)
- Сравнение двух каналов бок о бок по подписчикам, суммарным просмотрам, медиане, ER и темпу загрузок.

### 6. 🤖 AI Growth Studio (Заголовки и идеи)
- **AI Viral Titles**: генерация 8 кликабельных заголовков с прогнозом CTR (85–98%) и психологическими триггерами.
- **AI Video Ideas**: концепты роликов с хуками первых 5 секунд и описанием превью.
- **AI SEO Metadata**: готовые описания с таймкодами и 15 целевыми тегами для вставки в YouTube Studio.

## 🚀 Быстрый старт

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. (Опционально) Настройте API ключи в `.env`

Создайте или отредактируйте файл `.env`:

```env
YOUTUBE_API_KEY=ваш_youtube_data_api_v3_ключ
GEMINI_API_KEY=ваш_gemini_api_ключ_для_ai
```

> **Примечание:** Сервис поддерживает **демо-режим (Mock API)**. Если ключ не задан, все модули, графики и AI-генераторы работают на обучающих эвристиках и демонстрационных данных для моментального тестирования.

### 3. Запустите веб-платформу

```bash
python main.py
```

Или через uvicorn:

```bash
uvicorn app:app --port 8000 --reload
```

Откройте в браузере: **`http://127.0.0.1:8000`**

## 📁 Структура проекта

```
youtube_analytics/
├── app.py                     # FastAPI веб-сервер и REST API
├── main.py                    # Точка входа и автозапуск в браузере
├── requirements.txt           # Зависимости проекта
├── .gitignore                 # Исключение .env и временных файлов
├── services/
│   ├── youtube_service.py     # Интеграция с YouTube API v3, TTL-кэш, парсер URL
│   ├── seo_analyzer.py        # Движок расчета SEO Score (0-100) и чек-листа
│   ├── analytics_engine.py    # Расчет VPH, Outlier Multipliers, медианы и битвы каналов
│   ├── keyword_service.py     # YouTube Search Autocomplete и оценка ключевых слов
│   └── ai_assistant.py        # Интеграция с Gemini AI / вирусные заголовки и идеи
└── static/
    ├── index.html             # Современный SPA-интерфейс (темная тема)
    ├── app.js                 # Реактивная клиентская логика и графики ApexCharts
    └── style.css              # Стили, анимации и дизайн-токены
```
