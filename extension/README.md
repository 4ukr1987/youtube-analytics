# 🧩 YouTube Analytics & Growth Studio Chrome Extension

Браузерное расширение (Manifest V3), выводящее аналитику vidIQ-уровня прямо на страницах `youtube.com`.

---

### ⚡ Возможности расширения:
1. **Виджет на странице видео**:
   - Мгновенный расчет **SEO Score (0–100)**.
   - Подсчет текущей скорости **VPH (просмотры в час)**.
   - **Скрытые теги конкурентов** с кнопкой копирования в 1 клик.
   - Быстрый переход к транскрипции и глубокому аудиту.
2. **Popup меню**:
   - Быстрый доступ к дашборду, детектору аномалий и генератору идей.

---

### 🚀 Как установить расширение в Google Chrome / Brave / Edge / Яндекс.Браузер (за 30 секунд):

1. Откройте в браузере страницу:
   ```
   chrome://extensions/
   ```
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку проекта:
   ```
   /Users/roman/Gemini/youtube_analytics/extension
   ```

Готово! Теперь при открытии любого видео на `youtube.com` под плеером появится интерактивный виджет аналитики!
